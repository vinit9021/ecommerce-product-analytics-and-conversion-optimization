# Synthetic Experiment Readout

## Important

This is a synthetic statistical demonstration.

The GA4 public dataset does not contain a real experiment assignment, so the
results below must not be interpreted as observed product impact.

## Experiment Planning

- Baseline View → Cart rate: 17.03%
- Relative MDE: 10.0%
- Target conversion: 18.73%
- Significance level: 5%
- Statistical power: 80%
- Required sample size per variant: 7,944
- Total planned sample: 15,888

## Synthetic Readout

- Control conversion: 17.03%
- Treatment conversion: 18.73%
- Absolute lift: 1.70 percentage points
- Relative lift: 9.98%
- p-value: 0.0052
- 95% CI for absolute lift:
  0.51 to
  2.89 percentage points
- Statistical readout: SIGNIFICANT POSITIVE LIFT

## Interpretation

The synthetic example demonstrates how a Product Analyst would determine
whether an observed conversion lift is statistically distinguishable from
random variation.

A real ship decision would additionally require satisfactory guardrail
metrics and business significance.
